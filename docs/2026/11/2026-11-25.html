ACAP: Asynchronous Coding Agents for Efficient Robot Control

Apesar do domínio ser robótica, ACAP é um paper de orquestração: agentes persistentes controlam grupos independentes, enquanto um hyper-agent decide dependências e realoca controle. A parte transferível é a distinção entre paralelismo real e colaboração acoplada; delegação fixa perde quando a tarefa muda de independente para interdependente. Entra também pelo piso de popularização, com 67 upvotes.

Não use como prova de ganho multiagente genérico; use como padrão para alternar entre autonomia local e coordenação central.

SpecEngineeringBench: Evaluating Coding Agents as Autonomous Specification Engineers

SpecEngineeringBench avalia agentes como engenheiros de especificação autônomos, não como geradores de testes com ponto de entrada dado. O achado que importa é a dissociação: alta validade de testes e boa cobertura convivem com baixa conversão em defeitos encontrados. Isso é exatamente o tipo de benchmark que revela modo de falha, não só leaderboard.

Para o nosso casoNos seus gates de código, não aceite “gerou testes e cobriu linhas” como evidência suficiente. Separe métricas de validade, cobertura, exposição de defeito e precisão de localização; elas medem capacidades diferentes do agente.

RECAP: Training Long-horizon LLM Agents with Context Compaction

RECAP trata context compaction como uma intervenção na política do agente: se o resumo muda as próximas ações, ele distorceu o histórico. A novidade é otimizar a compressão pela divergência entre comportamento com contexto original e comportamento com contexto compactado, combinando recompensa para o resumo e self-distillation para ações posteriores. Os ganhos em BrowseComp-plus e SWE-bench Verified são modestos, mas a formulação é boa.

Para o nosso casoPara suas skills e memórias, avalie resumos perguntando: o agente faria o mesmo próximo passo com o histórico completo? Isso sugere um eval pareado de compaction, comparando plano, chamadas de ferramenta e evidências citadas sob contexto original versus compactado.
