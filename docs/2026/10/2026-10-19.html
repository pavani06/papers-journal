Skip the Compressor: Coding Agents Fix More Issues When They Pick Whole Files

O resultado é simples e incômodo para pipelines de context engineering: com o mesmo orçamento, escolher arquivos inteiros bate compressão e retrieval por chunks em SWE-rebench. A explicação é operacional, não estética: o agente precisa editar linhas exatas; retrievers perdem arquivos que precisam mudar, e compressors preservam a ideia mas danificam o texto editável.

Para o nosso casoPara o seu agente de código, trate seleção de arquivos como decisão primária e compressão como último recurso. Se uma skill vai editar, o contexto deve privilegiar arquivos completos e aplicáveis, mesmo que isso reduza a quantidade de material auxiliar.

EvoWeb: A Benchmark for Coding Agents on Evolving Web Applications

EvoWeb mede uma forma de trabalho que parece mais próxima de manutenção real: uma aplicação persiste e recebe pedidos sucessivos. O modo de falha revelado é útil: conforme dependências entre pedidos se aprofundam, caem as soluções corretas e aumentam erros de runtime, mesmo que cada pedido isolado pareça plausível.

Para o nosso casoUse isso como argumento para evals replayable de evolução, não só tarefas fresh checkout. O seu harness deveria testar regressão contra requisitos anteriores a cada nova intervenção, especialmente quando a skill mexe em fluxos já alterados por execuções passadas.
